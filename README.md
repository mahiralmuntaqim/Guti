# Brine Time (Unity)

Co-op low-poly fishing game, now on **Unity 6.6 (6000.6.6f1)** with **FishNet 4.7.3** networking.
The previous Godot version lives on the [`godot` branch](https://github.com/mahiralmuntaqim/Guti/tree/godot).

Quick start: install Unity Hub + Unity **6000.6.6f1**, open this folder in Unity Hub (**Add project from disk**),
open `Assets/BrineTime/Scenes/Main.unity`, press **Play**.
